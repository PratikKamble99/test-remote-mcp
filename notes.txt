uv is basically a modern replacement for pip + venv + pip-tools — all in one tool.

People use uv because it’s:
    -Much faster
    -Simpler
    -More reliable


initialize uv project
command - uv init . ( . = current directory ) 

Install dependency using uv
command - uv add <package-name>

Run local MCP dev server
command - uv run fastmcp dev inspector main.py

Run MCP server
command - uv run fastmcp run main.py
